# Framework Architecture

## AI Test Design Framework Generator V2.0

---

## 1. Overview

The AI Test Design Framework Generator V2.0 automatically converts AI-generated structured JSON test design into a production-ready Selenium automation framework.

The framework follows a modular generator architecture where every major framework component is generated by an independent generator class.

---

## 2. High Level Architecture

```
AI Requirement
      │
      ▼
LLM / AI Response
      │
      ▼
Structured JSON
      │
      ▼
AIResponseReaderV2
      │
      ▼
GeneratedTestSuite Model
      │
      ▼
Generator Classes
      │
      ▼
Generated Selenium Framework
      │
      ▼
TestNG Execution
      │
      ▼
Extent Reports
```

---

## 3. Generator Components

| Generator | Responsibility |
|-----------|----------------|
| ProjectStructureGeneratorV2 | Creates project folders |
| PomGeneratorV2 | Generates pom.xml |
| TestNGGeneratorV2 | Generates testng.xml |
| BasePageGeneratorV2 | Generates BasePage |
| DriverFactoryGeneratorV2 | Generates DriverFactory |
| BaseTestGeneratorV2 | Generates BaseTest |
| ConfigGeneratorV2 | Generates config.properties |
| ConfigReaderGeneratorV2 | Reads configuration |
| FrameworkVersionGeneratorV2 | Generates framework version |
| PageObjectGeneratorV2 | Generates Page Objects |
| SeleniumCodeGeneratorV2 | Generates TestNG Test Classes |
| WaitUtilityGeneratorV2 | Generates Wait Utility |
| ScreenshotUtilityGeneratorV2 | Generates Screenshot Utility |
| LoggerGeneratorV2 | Generates Logger Utility |
| ExtentReportGeneratorV2 | Generates ExtentManager |
| ExtentTestManagerGeneratorV2 | Generates ExtentTestManager |
| ExtentListenerGeneratorV2 | Generates Extent Listener |
| READMEGeneratorV2 | Generates README.md |
| GitIgnoreGeneratorV2 | Generates .gitignore |

---

## 5. Execution Flow

1. Read AI JSON response.
2. Convert JSON into GeneratedTestSuite.
3. Execute all generators.
4. Build Selenium Framework.
5. Execute TestNG suite.
6. Generate Extent Report.
